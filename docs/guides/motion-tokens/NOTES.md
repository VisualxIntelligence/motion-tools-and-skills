| File | What it is |
|---|---|
| `MOTION.md` | A brand motion-token template: hover 140 ms, state 220 ms, modal 280 ms, reveal 420 ms, signature 900 ms; stagger 40/60/90 ms; one house easing `[0.22, 1, 0.36, 1]`. Fill it in once per show or brand |
| `site-motion-excellence-gate.md` | A 12-category review gate scored 1–5, with automatic-fail conditions |
| `motion-quality-rubric.md` | A shorter motion quality rubric |

The token and rubric files were written for websites. For video, keep the structure: one easing family, a few named durations, one stagger value. Then scale the values up for broadcast (see [`../../../skills/motion-design-principles/NOTES.md`](../../../skills/motion-design-principles/NOTES.md)).
