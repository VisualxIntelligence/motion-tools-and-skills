# Tools

Scripts and utilities for rendering, checking and finishing motion graphics. Folders here are standalone tools; the table at the bottom also points to useful tools that live inside the skills.

| Folder | What it does | Stack | Source |
|---|---|---|---|
| [`headless-render/`](headless-render/NOTES.md) | Renders any time-pure HTML/canvas/WebGL page in headless Chrome: contact sheets, frame strips, tracked crops and stills for agent review; parallel resumable frames; ffmpeg encode with audio. Plus a GPU probe. | Node, puppeteer-core, ffmpeg | ClaudeAnimationBase (MIT) |
| [`lemo-core/`](lemo-core/NOTES.md) | A full code-film toolkit: parallel video render, review stills, reading-time check, events export, contact sheets, SRT, two-pass loudness master with grain; procedural SFX, sampler, plucked strings; offline and online TTS with a Whisper back-check; three.js post (GTAO, DoF, bloom) and a VHS/CRT pass. | Node + Playwright, Python, ffmpeg, three.js | lemo-opuscar (MIT) |
| [`song-analysis/`](song-analysis/NOTES.md) | Song → `audio.json` (beat grid, downbeats, sections, kick/snare/hat onsets from Demucs stems, 100 fps envelopes per stem) and `lyrics.json` (word-level lyric timing by CTC forced alignment, cross-checked with Whisper), with QA plots. The most thorough music-timing tool in the repo. | Python (uv), Demucs, torchaudio, librosa | pdoom-video (MIT) |
| [`tidewater-asset-pipeline/`](tidewater-asset-pipeline/NOTES.md) | Asset build scripts: CC0 Freesound search and download, loop crossfades and loudness normalisation to −23 LUFS; Blender batch scripts for FBX character → GLB with retargeted, NLA-baked clips, and glTF decimation to a triangle budget. | Node, ffmpeg, Blender 4.2–5.2 (background), Python | tidewater (MIT) |
| [`sync-check/`](sync-check/NOTES.md) | Checks a rendered MP4's sound against its picture: offset from each cut or cue to the nearest onset (OFF-BEAT beyond ±100 ms) and the loudness jump into it (STARTLE above +6 dB); exits 1 on failure | Node, ffmpeg | iart-ai/javascript-animation-skills (MIT) |
| [`mixamo-retarget/`](mixamo-retarget/NOTES.md) | 24 human joints (metres, Y-up) → a Mixamo-rigged character: binary FBX reader, T-pose calibration, swing/aim retarget, linear blend skinning, animated GLB writer. No Blender. Feed it from licensed mocap or MediaPipe; the video-to-joints models upstream are non-commercial | Python, numpy | Motion2MixamoRig (Apache-2.0; core only) |
| [`blender-mcp/`](blender-mcp/NOTES.md) | Notes for the MCP server that lets Claude drive an open Blender (installed with uv, not copied): its 15 tools (run Python, scene facts, `look` from several angles, Poly Haven/Sketchfab assets, text/image → 3D, Gaussian-splat worlds), Windows setup, telemetry and safe mode, and how it pairs with the Blender skills | Python (uv), Blender add-on | ahujasid/blender-mcp (MIT) |
| [`mesh-pipeline/`](mesh-pipeline/NOTES.md) | Our own scripts, tested: Tripo text/image → GLB with a credit report; a parametric build123d prop → STEP/GLB/STL; PyMeshLab clean and repair with a before/after report; xatlas automatic UVs; a meshoptimizer LOD chain that keeps named parts. Plus the lessons the tests taught (PyMeshLab selections, `gltf-transform optimize` defaults, code-CAD UVs) | Python (pymeshlab, xatlas, trimesh, build123d, tripo3d), Node (glTF-Transform, meshoptimizer) | Our own (MIT); wraps GPL-3.0 PyMeshLab without copying it |
| [`awwwards-mcp/`](awwwards-mcp/NOTES.md) | Notes for an MCP server (installed from npm, not copied): award-winning web references, and measurement of any page or your own build: motion DNA (libraries, easing and duration vocabulary, scroll model), scroll and hover census, motion-through recordings, GSAP stubs, 3D canvas captures, runtime performance evidence | Node 22.13+, Playwright, ffmpeg-static | INSANE0777/Awwwards-mcp (MIT) |
| [`raea/`](raea/NOTES.md) | Notes for raea, the Render Anything Engine (installed from a release, not copied): React + TypeScript compositions rendered on your own GPU by a Rust/Bevy engine, with a Remotion-like API, 3D (R3F, glTF, splats), an engine mixer, `raea check` and agent skills. Windows is the least-tested platform and has no hardware encode yet | Rust engine, TypeScript SDK; DX12/Vulkan on Windows | shinyobjectz/raea (FSL-1.1-ALv2: no competing products) |
| [`tdmcp/`](tdmcp/NOTES.md) | Notes for Derivative's official TouchDesigner MCP (26 tools: build and wire operators, write DAT and GLSL, inspect CHOPs and TOPs, capture output, cook times, docs) and its 19 skills; setup for Claude Code; licence tiers (Non-Commercial is 1280×1280 and unpaid work only) | TouchDesigner 2025.33230+, streamable-HTTP MCP | TouchDesigner/TDMCP (Shared Use License) |
| [`kdenlive-mcp/`](kdenlive-mcp/NOTES.md) | Notes for a headless agent video editor: a revisioned JSON project compiled to MLT; clips, keyframes, effects, transitions, text, captions; render jobs with A/V sync, loudness, clipping, black and freeze checks; editable Kdenlive and OTIO export for Resolve. Tested on Windows | Node 22+, pnpm 9, Kdenlive 26.04 (MLT, FFmpeg) | AMMIROSOH/Kdenlive-mcp (Apache-2.0) |
| [`open-fusion-mcp/`](open-fusion-mcp/NOTES.md) | Notes for an MCP server and skills that build editable Fusion node graphs in DaVinci Resolve (181 checked operations, a scene builder, render-and-look, recovery). **macOS only for now; watch, don't install** | Python 3.12, Resolve Studio 21.1 | legionsound/open-fusion-mcp (MIT) |
| [`comfyui-piflow/`](comfyui-piflow/NOTES.md) | Notes for ComfyUI nodes that make MiniMax H3 video with audio in 2–4 steps (pi-H3), plus AsymFlow and pi-Flow images; upstream timings, the SM89 (4090) and SM86 (3090) workflows, model files and licence cautions | ComfyUI 0.45+, NVIDIA GPU | Lakonik/ComfyUI-piFlow (Apache-2.0; models vary) |
| [`frame-interpolation/`](frame-interpolation/NOTES.md) | RIFE frame interpolation: ComfyUI's built-in node and the Practical-RIFE CLI, which model to use (4.25/4.26), and when not to (code-rendered graphics, across cuts) | ComfyUI 0.46 or Python ≤ 3.11 + PyTorch | hzwer/Practical-RIFE (MIT) |
| [`photo-parallax/`](photo-parallax/NOTES.md) | One photo → a moving-camera shot: metric or relative depth, panoptic segments, sky/ground-aware depth layers with soft-edged cards, background fill (OpenCV, or SDXL inpainting on a GPU), and a time-pure three.js page that renders dolly, truck, orbit, crane-up and vertigo moves at any aspect with an automatic edge guard. Research-only models are refused unless confirmed; a commercial-safe recipe is documented. Tested on CPU | Python (torch, transformers, scipy, scikit-image, OpenCV, diffusers), Node (three, Playwright), ffmpeg | Our own (MIT); models from Apple, Meta, Stability/Diffusers, Depth Anything |
| [`depth-anything/`](depth-anything/NOTES.md) | Depth from one photo for 2.5D parallax, single-image meshes and depth compositing: ComfyUI's built-in Depth Anything 3 nodes and the V2 CLI, with **which checkpoints are licensed for commercial use** and picture-rights rules | ComfyUI 0.46 or Python + PyTorch | Depth Anything V2 / 3 (code Apache-2.0; larger models CC-BY-NC)
