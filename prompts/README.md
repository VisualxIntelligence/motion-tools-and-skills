# Prompts

Prompts, briefs and templates for directing an agent to make motion graphics.

| Folder / file | What it is | Source |
|---|---|---|
| [`film-styles/`](film-styles/README.md) | 51 film-style prompts (including eight Evidence Films styles built from real, sourced material) in one 11-section schema (essence, materials, colour, type, motion, camera grammar, sound, native moves, pitfalls, engine, variation), with an index table. The schema is a good model for writing a house graphics style. | lemo-opuscar (MIT) |
| [`video-prompts/yihui-prompt-index.md`](video-prompts/yihui-prompt-index.md) | 64 of the most useful prompts from a collection of 703 Opus 5.5 videos (40 chosen on 6 October, 24 more on 21 October), chosen for a broadcast motion team: kinetic type, product launches, explainers, title and logo pieces, music video, 3D. Author, link, stack and our notes; the prompt text itself stays upstream (it belongs to each creator). | yihui-dev/awesome-opus5-5-videos (MIT; prompts © creators) |
| [`../starters/mg-styles-15/prompts/`](../starters/mg-styles-15/prompts/) | 15 motion-design style prompts in one shared frame (output spec, technical route, creative seed by the second, testable signature features), each with the source of the film it made; plus [`template.md`](../starters/mg-styles-15/template.md) for writing a new style and [`rubric.md`](../starters/mg-styles-15/rubric.md), a jury prompt for review rounds | mg-styles-15 (MIT) |
| [`video-prompts/athemeroy-motion-cases.md`](video-prompts/athemeroy-motion-cases.md) | 40 motion-relevant cases from a source-checked guide to 1,000+ videos, each with stack, the *shape* of the prompt (paraphrased) and what to use it for; plus four prompt templates translated from Chinese. | athemeroy/awesome-opus-5-5-videos (CC BY 4.0, adapted) |
